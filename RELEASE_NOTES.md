# HyperMix 1.0.0

Первый публичный релиз. Дата: 23 октября 2026.

HyperMix — портативная звуковая панель с глобальными горячими клавишами и
виртуальным микрофоном. Звуки панели и голос с реального микрофона
смешиваются автоматически — в Discord или игре достаточно выбрать один
виртуальный микрофон.

## Артефакты

| Файл | Назначение |
|------|------------|
| `HyperMix-1.0.0-Linux-x86_64.tar.gz` | готовый Linux-бинарник |
| `HyperMix-1.0.0-Windows-build-kit.zip` | исходники + сборка Windows exe |
| `HyperMix-1.0.0-source.tar.gz` | исходники релиза |
| `SHA256SUMS` | контрольные суммы |

Проверка:
```bash
sha256sum -c SHA256SUMS
```

## Linux

```bash
tar -xzf HyperMix-1.0.0-Linux-x86_64.tar.gz
cd HyperMix-1.0.0-Linux-x86_64
./HyperMix
```

- Установка не требуется; Python внутри сборки.
- Нужен `pactl` (PipeWire или PulseAudio).
- Глобальные клавиши читают `/dev/input/event*`: добавьте пользователя в
  группу `input` или установите udev-правило. Без доступа используется
  KGlobalAccel.
- Виртуальный микрофон `HyperMix_Mic` создаётся при запуске и удаляется при
  закрытии.
- Сборка сделана на glibc 2.44 (Arch Linux). На старых системах
  (например, Ubuntu 20.04) используйте исходники и `./build_linux.sh`.

## Windows

Готовый Windows `.exe` собирается на Windows: PyInstaller не умеет
кросс-компилировать с Linux.

1. Распакуйте `HyperMix-1.0.0-Windows-build-kit.zip`.
2. Установите Python 3.10+ (галочка «Add python.exe to PATH»).
3. Запустите `build_windows.bat`.
4. Получите `release\HyperMix-1.0.0-Windows-x86_64.zip` с `HyperMix.exe`.

Для работы:
- установите VB-Audio Cable: https://vb-audio.com/Cable/
- перезагрузите Windows;
- в Discord/игре выберите микрофон **CABLE Output**;
- при необходимости разрешите доступ к микрофону в параметрах Windows.

Голос подмешивается в `CABLE Input` встроенным микшером HyperMix;
включать «Прослушивать с данного устройства» не нужно — будет эхо.

## Что нового

- Звуковая панель: WAV, MP3, OGG, FLAC; глобальные клавиши и боковые кнопки мыши.
- Режимы `[SPK]` / `[MIC]` / `[BOTH]`.
- Linux: `HyperMix_Mic` + loopback, evdev с откатом на KGlobalAccel.
- Windows: VB-Cable, `sounddevice`, автоматический микс голоса, выбор микрофона.
- Темы Light / Dark / Hacker с анимацией «Матрица».
- Портативный `config.json` рядом с приложением.
- `HyperMix --version`, `--check`, `--send` для диагностики и интеграций.

## Известные ограничения

- Windows-сборка не подписана сертификатом: SmartScreen может показать
  предупреждение. Выберите «Подробнее» → «Выполнить в любом случае».
- Готовый Windows exe не проверен на реальном оборудовании в этом окружении;
  проверка выполнялась на Linux + эмуляция PortAudio.
- Для Linux-бинарника нужна система с glibc не старше сборочной.
