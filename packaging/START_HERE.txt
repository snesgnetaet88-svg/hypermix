HyperMix — Windows
==================

Готовый файл: HyperMix.exe (в этой папке).
Запускайте его двойным кликом. Установка не требуется.

Первый запуск:
1. Установите VB-Audio Cable: https://vb-audio.com/Cable/
   (HyperMix сам откроет страницу, если драйвера нет).
2. Перезапустите Windows.
3. Запустите HyperMix.
4. В Discord/игре выберите микрофон CABLE Output (VB-Audio Virtual Cable).

Голос и звуки панели HyperMix смешивает автоматически.
Если в статусе «голос не найден»: Параметры → Конфиденциальность →
Микрофон → разрешить классическим приложениям доступ к микрофону.

Если Windows SmartScreen предупреждает о неизвестном издателе —
это нормально для бесплатной сборки без платной подписи. Нажмите
«Подробнее» → «Выполнить в любом случае».

Настройки (тема, звуки, хоткеи, микрофон) хранятся в config.json
рядом с HyperMix.exe. Для переноса просто копируйте папку целиком.
